    Here's a step-by-step guide to get your portfolio live on GitHub Pages:

    Step 1: Create a GitHub Account

    • Go to github.com and sign up if you don't already have one

    Step 2: Create a New Repository

    • Click the "+" icon in the top right corner
    • Click "New repository"
    • Name it exactly: yourusername.github.io (replace "yourusername" with your actual GitHub username — this part is critical!)
    • Set it to Public
    • Check "Add a README file"
    • Click "Create repository"

    Step 3: Upload Your Files

    • In your new repository click "Add file" → "Upload files"
    • Upload all of these at once:
      • index.html (the code I gave you)
      • headshot.jpg (your photo)
      • crystal.jpg (your lab photo)
      • cv.pdf (your CV)
    • Click "Commit changes"

    Step 4: Enable GitHub Pages

    • Go to Settings (top menu of your repository)
    • Scroll down the left sidebar and click "Pages"
    • Under "Source" select "main" branch
    • Click "Save"

    Step 5: Visit Your Live Site

    • After 1-2 minutes your site will be live at:
      https://yourusername.github.io

    The most common mistake is naming the files wrong — make sure your photos and CV are named exactly headshot.jpg, crystal.jpg, and cv.pdf to match what's in the code. Want me to help with anything else?
